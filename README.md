# pipeipv4

Pipe host/ipv4 network string helpers for config audits.

**Site:** https://theworker02.github.io/pipeipv4/

## Install / run

```bash
git clone https://github.com/theworker02/pipeipv4.git
cd pipeipv4
node src/cli.js
node --test
```
